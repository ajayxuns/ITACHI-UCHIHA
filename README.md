## 👁️ 𝐆 𝐄 𝐍 𝐉 𝐔 𝐓 𝐒 𝐔 // Overview

An immersive, cinematic web experience paying tribute to **Itachi Uchiha**. Built purely with the core trifecta of web development, this project captures the essence of the Clan's tragic hero through atmospheric visual design, smooth animations, interactive gaze-tracking, and forbidden Uchiha jutsu.

---

## 🩸 𝐅 𝐄 𝐀 𝐓 𝐔 𝐑 𝐄 𝐒

* **覚醒 Awakening:** Interactive scroll-driven transition into the crimson gaze of the Sharingan.
* **見つめ返せ Gaze Tracking:** Dynamic real-time cursor tracking mapped directly to the Mangekyō pupil movements.
* **烏 A Thousand Crows:** Ambient feather and crow dispersion effects simulating the classic clone illusion.
* **天照 Forbidden Arts (Jutsu):** Showcasing Amaterasu, Tsukuyomi, and the legacy of the shadow shinobi.
* **Cinematic Dark UI:** High-contrast crimson and obsidian typography with Japanese calligraphy accents.
